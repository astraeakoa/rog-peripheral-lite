# v0.3.1 更新（2026-10-21）

后续修订（保持版本号）：

- 宏编辑器按宏编辑、按键绑定分区，统一字段高度、按钮组、主题和下拉菜单样式。
- 编辑动作只提供 Down / Up / Delay；延迟在动作前执行，旧 Press 自动展开，支持在选中行之前插入。
- 新行先选动作或按键时补全另一字段；Delay 禁用按键栏，延迟输入进行整数及范围校验。
- 下拉框静态与编辑状态使用同一绘制逻辑，统一文字位置、箭头和边框；按键列表使用鼠标 Keyboard 分类条目及左右键。
- 插入和移动之前检查编辑提交结果，删除后保留有效选择；增加空列表、首尾边界、中间插入、删除、未提交延迟及无效输入回归检查。
- UI 自动检查失败时返回非零退出码。真实鼠标点击验证状态详见 [宏编辑测试记录](MACRO_EDITOR_QA.md)。

- 新增 Armoury Crate 文本 GMAC 子集导入导出；末尾独立 `1` 按固定标记处理，未知事件与编码报错。
- 新增鼠标左右键的点按、按住、松开及异常/停止时释放；明确不支持中键、侧键、滚轮和移动。
- GMAC 仅传递步骤，导出前提示不包含播放设置；JSON/CSV/AHK 同步支持左右键。
- 用用户提供文件验证 128 步、14340 ms 延迟、62 个输入事件及 GMAC 往返一致；验证不向桌面注入输入。

# v0.3.0 更新

- 接入原版主题跟随逻辑：系统颜色变化时刷新所有已打开的设置窗口、宏表格及托盘菜单，保留编辑状态。
- 启动时读取 `language`，未指定时沿用系统界面语言。保留上游多语言资源。
- 新增界面及宏错误提示使用 .resx 资源，提供英文、简体中文、繁体中文，其他语言回退至英文。
- `ui_mode` 和 `language` 使用独立版配置目录，手动修改后重启生效。

# v0.2.4 更新

- 图标改为蓝底白色大写 G，搭配青绿色闪电点缀，突出原版 G 字母辨识度。

# v0.2.3 更新

- 新增鼠标与青绿色闪电图标，应用于程序文件、主窗口和系统托盘，包含 16–256 像素多尺寸资源。

# v0.2.2 更新

- 移除主界面底部说明文字，底部固定显示程序版本号。

# v0.2.1 更新

- 所有设置窗口禁用拖拽缩放和最大化，保留系统 DPI 缩放。
- 主界面的设备、宏按键和刷新设备卡片改为固定竖排；设备较多时可滚动。

# v0.2 更新

- 宏导入与导出：原生 JSON、CSV 步骤表、AutoHotkey v1/v2 的直线型按键/延迟子集；导入先预览，错误不覆盖编辑器。
- 新增单次按下、连续触发（再次按下停止）、按住触发（松开停止），可设置每轮次数及循环间隔。
- 通过按下/松开事件处理触发，过滤按键自动重复和程序注入的触发键。
- 停止/异常/退出时释放已按下的键；切换系统会话和休眠时停止运行。
- 主界面沿用 G-Helper 图标、电量条和灰色圆角卡片；新增界面使用 Segoe UI 8 字号。
- 验证：41 项自动检查；浅色与深色 UI 渲染；Windows 按键监听初始化。物理侧键触发仍需实机手动确认。
